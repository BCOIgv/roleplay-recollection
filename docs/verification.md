## 2. 覆盖的行为

### 核心记忆

- 工作模式不捕获、不回想、不注入想法、不调用模型。
- 低显著性经历被过滤；重复来源不会重复入库或强化。
- 同一来源不能换 ID 变成多段经历，也不能绕过撤回。
- 线索回想能命中相关经历；不相关线索不强行发挥。
- 中文线索按二元组匹配；`reported` 经历保持「用户陈述」语义。
- 剧情事件只在对应 `storyId` 内流动，不进入现实陪伴。
- 普通细节随时间从具体退到印象，最终离开日常候选；明确保留例外。
- 淡化后模型看不到原句、精确时间；旧私人想法不能成为绕过淡化的后门。
- 回想本身不产生新事实、来源经历、特质或私人想法。
- 私人想法不能重新入库为来源经历。
- 沉默是完整结果；私人时刻可以只留下暂定想法。
- 重复开场受冷却与同段旧事间隔限制。
- 非法记忆引用、不可见 anchor、模型篡改输入都会被拒绝。
- 暂停、遗忘、来源修订/撤回会拒绝晚到结果并清除衍生内容。
- 模型超时、关闭、重启恢复、角色/范围隔离。
- 无运行时依赖、无网络、无定时器、无平台传输。

### 独处与联系

- 机会持久化；轮询和重启不重抽；过期只跳过一次，不补跑。
- 新增经历可加速同一次机会；批量导入不会叠加成多次。
- 忙碌、等回复、最近活动、缺少真实活动证据时不启动。
- 随机采样不是总选最高重要性。
- 用户当前问题不会进入独处输入。
- 停留、弱关联、换念头、离开；淡化记忆不泄露隐藏细节。
- 每日预算与线索回想共享；失败尝试计入预算。
- 任务信号中断；模型失败不立刻重试。
- 分享意愿只在结束后产生；未取用/未发送不消耗联系额度。
- 未回应冷却、意愿过期、正常回复消费、未知投递不重放。
- 来源撤回使待用意愿失效；重启把中断的独处当作已结束。
- 过期写入锁可回收；存活写入者的锁不被抢。

## 3. 未验证

以下内容**没有**被本轮离线测试证明：

- 真实模型输出的自然度、角色一致性、是否显得打扰；
- QQ / DSH / 其他平台的端到端投递、回执与限流；
- 真实用户数据的提取质量与隐私合规；
- 长时间运行、并发进程、磁盘异常下的稳定性；
- 不同 Node 版本/操作系统上的全部兼容性（CI 覆盖 Node 22/24、Linux/Windows 的基础路径）。

这些需要在接入宿主后进行单独验收，不能把本页的 56 项离线检查当作生产证明。

## 4. 复现

要求 Node.js ≥ 22：

```bash
npm test          # 56 项测试
npm run check     # 语法与包元数据
npm run verify    # 语法 + 测试 + 三个示例
npm run demo:basic
npm run demo
npm run demo:solitude
```

`npm run verify` 不会写报告文件，也不会访问网络；输出为一段 JSON 摘要。
